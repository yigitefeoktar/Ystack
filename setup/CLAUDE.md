# Shared personal setup

Personal skills in `~/.claude/skills/` link to the same active skill folders used by Codex. Keep their explicit activation requirements. A skill being installed does not activate its workflow or authorize external actions.

For T3 workflows, read the shared T3_SETUP.md beside the imported Codex AGENTS.md when needed. Use the tools available in this Claude/T3 session. T3 project/thread and preview tools take precedence over legacy desktop API examples. Instructions that require Codex desktop project/chat tools or desktop plugins need those tools to be available; report a missing capability instead of pretending the action succeeded.
