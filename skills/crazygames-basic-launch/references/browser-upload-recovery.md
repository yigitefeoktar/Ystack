# Browser upload recovery

Use only when portal control, file selection, upload, preview, or media conversion fails. Reinspect the current page and tab before retrying; do not assume a prior session's UI or unsaved state remains valid.

1. Identify the active tab with the user's latest edits and retain it. Leave unsaved Details and ongoing uploads in their current tab. If the hosted preview fails, look up the game in **My Games** and retry QA from the existing draft before considering a replacement upload. On a duplicate-name error, open the matching draft from **My Games** and verify the title, build, and user-selected orientation.
2. If using the ChatGPT/Codex Chrome extension and file selection is unavailable, check the current [official extension instructions](https://learn.chatgpt.com/docs/chrome-extension). In Chrome's extension Details, the user may need to enable **Allow access to file URLs**, then restart the browser task. Confirm the active browser profile and extension connection. Update/restart the desktop app or browser only when connection diagnostics warrant it; do not uninstall extensions as a routine step.
3. Start the file-chooser wait before clicking the specific Upload button, then give the chooser the absolute local file path. For a cover, if a crop dialog appears, accept the intended full-image crop. For a video, wait for uploading **and** conversion to finish. Re-read actual page state after each file.
4. If the cropper reports `Maximum call stack size exceeded`, `Failed to fetch`, or a persistent `Uploading image...`, inspect whether the upload is still progressing. Wait in bounded intervals without refreshing, then retry **only** the file whose Upload control remains available. Do not re-encode or substitute a different asset unless the original has truly failed and the replacement has been inspected.
5. Before proceeding, confirm all required thumbnails and video-complete controls are present, no pending indicators or errors remain, then report the page for review. Save or continue after approval and verify persistence. A transient thumbnail before saving is not durable completion.
