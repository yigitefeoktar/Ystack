# Ystack

A collection of Codex and Claude Code skills for building, reviewing, and publishing browser games. Browse [the skills](skills/) or see [setup and installation](setup/README.md) for the installer, shared instructions, and T3 Code guidance.

## Skills

| Skill | Use it for |
| --- | --- |
| [Confirm Task Understanding](skills/confirm-task-understanding/SKILL.md) | Check the plan and resolve important ambiguities before work. |
| [Game Audio Review](skills/game-audio-review/SKILL.md) | Hear and compare sound effects in a playable preview. |
| [ByteBrew Game Analytics](skills/bytebrew-game-analytics/SKILL.md) | Add or verify analytics without affecting gameplay. |
| [Game Deployment](skills/game-deployment/SKILL.md) | Deploy a game to Vercel and handle an optional Windows backend. |
| [CrazyGames Basic Launch](skills/crazygames-basic-launch/SKILL.md) | Verify the game build, prepare media, and set up a portal draft. |
| [Manage Games Hub](skills/manage-games-hub/SKILL.md) | Prepare and route a listing update to the configured Games Hub. |
| [Master Project Manager](skills/master-project-manager/SKILL.md) | Coordinate chats in a game project. Invoke explicitly. |

The name is a nod to [Garry Tan's gstack](https://github.com/garrytan/gstack). Ystack is an independent collection, not a fork, port, or affiliated project. It does not include gstack code. See the [MIT license](LICENSE).
